# RecoverAI — Data Model & Entity Specifications

> **Razorpay Buildathon 2026** | Database Architecture Specifications

This document defines the relational database entities, fields, data types, indexes, and relationships implemented using SQLAlchemy for RecoverAI.

---

## Entity Relationship Summary

```text
+-------------------+       1:N       +---------------------+
|     Customer      |---------------->|       Payment       |
```

## Entity Specifications

### 1. `Customer` (`customers` table)
Represents a business customer / payer.

| Field Name | Type | Constraints / Attributes | Description |
| :--- | :--- | :--- | :--- |
| `id` | Integer | Primary Key, Autoincrement | Internal surrogate key |
| `customer_id` | String(64) | Unique, Indexed, Non-null | Business ID (e.g. `cust_01001`) |
| `name` | String(128) | Non-null | Customer full name |
| `email` | String(128) | Indexed, Non-null | Customer email address |
| `phone` | String(32) | Nullable | Customer mobile number |
| `lifetime_value` | Float | Default `0.0` | Total historical spending (INR) |
| `total_payments_count` | Integer | Default `0` | Cumulative total payment attempts |
| `successful_payments_count` | Integer | Default `0` | Cumulative successful payments |
| `success_rate` | Float | Default `1.0` | Historical success ratio ($0.0 - 1.0$) |
| `created_at` | DateTime | Non-null | Creation timestamp |
| `updated_at` | DateTime | Non-null | Last updated timestamp |

---

### 2. `Payment` (`payments` table)
Represents a failed payment transaction under recovery evaluation.

| Field Name | Type | Classification | Description |
| :--- | :--- | :--- | :--- |
| `id` | Integer | Internal | Primary key |
| `payment_id` | String(64) | Feature Input | Unique payment identifier (e.g. `pay_100001`) |
| `customer_id` | String(64) | Feature Input (FK) | Reference to `customers.customer_id` |
| `amount` | Float | Feature Input | Transaction amount (INR) |
| `currency` | String(10) | Feature Input | Currency code (`INR`) |
| `payment_method` | String(32) | Feature Input | `upi`, `card`, `netbanking`, `wallet`, `emi` |
| `failure_reason` | String(64) | Feature Input | Code explaining why payment failed |
| `timestamp` | DateTime | Feature Input | Timestamp of payment failure |
| `previous_attempts` | Integer | Feature Input | Number of immediate payment retries |
| `previous_recovery_attempts` | Integer | Feature Input | Interventions executed so far ($0, 1, 2$) |
| `time_since_failure_minutes` | Float | Feature Input | Elapsed minutes since failure |
| `status` | String(32) | State Field | `FAILED`, `RECOVERED`, `STOPPED`, `PENDING` |
| `recovery_score` | Float | Model Score Output | Calculated 0–100 score |
| `recovery_probability` | Float | Model Score Output | Estimated probability ($0.0 - 1.0$) |
| `expected_recovery_value` | Float | Model Score Output | $\text{Amount} \times \text{Probability}$ |
| `recovered` | Boolean | **Ground-Truth Label** | `True` if successfully recovered in ground truth |
| `amount_recovered` | Float | **Ground-Truth Label** | Actual recovered amount |

---

### 3. `RecoveryAttempt` (`recovery_attempts` table)
Records physical recovery interventions executed by RecoverAI.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | Integer | Primary key |
| `attempt_id` | String(64) | Unique attempt identifier |
| `payment_id` | String(64) | Foreign key to `payments.payment_id` |
| `attempt_number` | Integer | Sequence number ($1, 2$) |
| `action_type` | String(32) | `RETRY`, `PAYMENT_LINK`, `WAIT`, `STOP`, `HUMAN_REVIEW` |
| `status` | String(32) | `SUCCESS`, `FAILED`, `PENDING`, `BLOCKED` |
| `response_payload` | Text | JSON response from Razorpay API |
| `error_message` | Text | Error message if failed |

---

### 4. `RecoveryDecision` (`recovery_decisions` table)
Records the reasoning and decision trace generated by the AI Decision Agent & Guardrail Layer.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | Integer | Primary key |
| `decision_id` | String(64) | Unique decision identifier |
| `payment_id` | String(64) | Foreign key to `payments.payment_id` |
| `recovery_score` | Float | Score evaluated at decision time |
| `recovery_probability` | Float | Probability estimated by agent |
| `expected_recovery_value` | Float | Expected value evaluated |
| `proposed_action` | String(32) | Action proposed by AI Decision Agent |
| `guardrail_status` | String(32) | `ALLOWED`, `MODIFIED`, `BLOCKED` |
| `executed_action` | String(32) | Final action dispatched after guardrails |
| `confidence` | Float | Model confidence ($0.0 - 1.0$) |
| `reasoning_summary` | Text | Human-readable explanation |

---

### 5. `AuditLog` (`audit_logs` table)
Provides immutable event logs for every action and state transition.

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `id` | Integer | Primary key |
| `log_id` | String(64) | Unique audit log ID |
| `payment_id` | String(64) | Foreign key to `payments.payment_id` |
| `customer_id` | String(64) | Foreign key to `customers.customer_id` |
| `event_type` | String(64) | Event type code (e.g. `PAYMENT_FAILED`, `GUARDRAIL_CHECK`) |
| `actor` | String(32) | `SYSTEM`, `AI_AGENT`, `GUARDRAIL`, `MERCHANT` |
| `details` | Text | JSON serialized event metadata |
